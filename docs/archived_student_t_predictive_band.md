# Archived Student-t predictive band for future independent scalar G measurements

## Purpose

This document describes a historical frozen Student-t posterior-predictive calculation. Given the quoted standard uncertainty of one future independent scalar determination of G, the archived calculation produces a central 95% posterior-predictive interval for that determination's reported G value.

It is retained for computational provenance only. It is not the primary predictive model, is not a current manuscript claim, and is not regenerated by the current reproduction suites.

## Frozen training and model

The training archive is the complete 16-point `data/codata_2018_g.yaml` dataset. No NIST-2026 data are used.

The fitted model is the repository's canonical hierarchical multivariate Student-t model:

`y ~ MvStudentT(nu, mu*1, Sigma)`

with

`Sigma = lambda^2*S_reported + tau^2*I`.

For a future independent scalar measurement with quoted standard uncertainty `u`, expressed relative to the frozen reference G value, the draw-specific scalar Student-t scale is

`scale_new = sqrt(lambda^2*u_std^2 + tau^2)`.

The predictive interval marginalizes over the frozen posterior draws for `mu`, `tau`, `lambda`, and `nu` and then takes the empirical 2.5%, 50%, and 97.5% quantiles of deterministic seeded posterior-predictive draws.

The active historical covariance convention is `k=1.0`. The CODATA-2018 source retains its original source expansion metadata, but the active covariance supplied to the model uses the unexpanded standard uncertainties.

## Frozen posterior and sampler

The protocol uses the already-saved `results/nuts_reference/free.nc` posterior produced by the validated canonical NUTS configuration: four chains, 4,000 retained draws per chain, 2,000 tuning iterations, target acceptance 0.95, seed `20260903`, with the native NUTS progress bar disabled.

The archived analysis records hashes of the training dataset, frozen posterior reference, sampler script, and analysis script as provenance for the particular archived run. These recorded hashes are not cross-platform equality requirements for regenerated NUTS artifacts; the repository-wide frozen byte-hash checks are limited to the authoritative input datasets in `data/MANIFEST.json`. The archive metadata also records the Python and Bayesian package versions observed when the archived analysis was generated; these recorded versions are evidence about the frozen artifact's provenance, while the repository's declared Bayesian environment remains the target for a later clean-environment revalidation.

## Future-data eligibility

An eligible future observation must be a genuinely future scalar determination that was not included in the 16-point training archive and was not used to fit, tune, select, or validate the archived band. It must be produced independently enough that treating it as a new scalar experiment is defensible under the documented experimental provenance; in particular, a four-configuration correlated vector from a single apparatus is not an unchanged application of this scalar protocol.

Eligibility must be assessed and recorded before the frozen interval or predictive tail is confronted with the observation.

## Future scoring and update rule

Before any refit that incorporates the future observation, compare its observed scalar value with the stored central 95% interval, or calculate its posterior-predictive tail probability using the same frozen model and draws.

If the model or training archive is later changed, create a new dated/versioned archived band and preserve the earlier output unchanged.

## What the band does not mean

It is not a confidence interval for the physical constant G, not a CODATA recommendation, not a band for a correlated multi-configuration apparatus vector, and not a criterion for identifying a causal mechanism.
