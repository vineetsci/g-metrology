# Manuscript artifacts

The files in this directory are generated from the clean repository, using the authoritative data in `data/`, the shared implementation in `src/g_metrology/`, and the named analyses in `analyses/`.

## Generate

```bash
python paper/make_figures.py
python paper/make_tables.py
```

The generated PDFs/PNGs and LaTeX tables are outputs. They are not independent sources of scientific truth.

## Manuscript-facing figures

- `fig1_historical_archive` — historical determinations with reported and proportional-inflated uncertainties; the inflation scale is the fitted historical `lambda_MLE`.
- `fig2_nist_internal_dispersion` — NIST 2026 four-configuration internal scatter, showing the reported uncertainties, GLS mean ±1 SE, and the internal NIST inflation reference used in the figure.
- `fig3_torque_common_offset` — four-configuration free-minus-servo torque differences and common-offset fit.

## Manuscript-facing tables
- `table1_historical_dispersion` — Consistency of the CODATA-2018 archive under the proportional covariance-scale model.
- `table2_variance_models` — BIC comparison of covariance-inflation models for the complete archive.
- `table4_prospective_nist` — Prospective predictive comparison for the lineage-related 2026 NIST configuration vector.
- `table6_torque_models` — Comparison of the absolute-offset and fractional-scale torque models.

## Non-manuscript-facing tables
- `gaussian_predictive_band` — AUXILIARY Gaussian predictive-band output generated by the Paper suite; NOT a numbered manuscript table.
